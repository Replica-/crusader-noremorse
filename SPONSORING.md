# Sponsoring

This project is developed in my spare time, and a large part of the work is done with the help of an AI coding assistant, which has a recurring cost. Every contribution helps the work continue and lets new features (higher resolutions, PortMaster release, more game versions, and so on) arrive sooner.

## How to support the project

- **Tip / donate:** [Buy Me a Coffee](https://buymeacoffee.com/sebsebseb1982).

Sponsoring is entirely optional. The project stays free and open source under the [GNU GPL v3](LICENSE) whether or not you contribute financially.

## Other ways to help

Not everyone can or wants to give money, and that's fine. You can help just as much by:

- reporting bugs, ideally with a savegame that reproduces them;
- testing on different hardware, especially PortMaster handhelds;
- sending pull requests (see [CONTRIBUTING.md](CONTRIBUTING.md));
- spreading the word to other *Crusader* fans.

Thank you!
